# Corrige cálculo de frete para CEPs do Norte

_PR-102 · exemplo-repo · requisito: PROJ-134 (Frete regional)_

## Resumo Geral

Correção de bug no cálculo de frete: CEPs da região Norte estavam usando a tabela padrão em vez da tabela específica TABELA_FRETE_NORTE. Adicionado teste de regressão.

## Resumo para Gestores

Corrigimos um erro que fazia clientes do Norte pagarem um frete incorreto. Também adicionamos uma verificação automática para evitar que esse problema volte a ocorrer.

## Ações

### Backend

#### act-001 — Correção

**Descrição:** Corrige calcularFrete para usar TABELA_FRETE_NORTE quando o CEP pertence à região Norte, em vez da tabela padrão.

**Para gestores:** Corrigido o valor de frete cobrado de clientes da região Norte, que estava incorreto.

**Justificativa:** Clientes da região Norte estavam recebendo frete calculado com a tabela errada, gerando cobranças incorretas.

**Arquivos impactados:**
- `src/services/frete.ts`

```
if (regiao === 'norte') {
  return TABELA_FRETE_NORTE[cep];
}
return TABELA_FRETE_PADRAO[cep];
```

### Testes

#### act-002 — Criação

**Descrição:** Adiciona caso de teste unitário cobrindo CEPs da região Norte no cálculo de frete.

**Para gestores:** Criado um teste automático para evitar que esse erro de frete volte a acontecer.

**Justificativa:** Não havia teste cobrindo o caso da região Norte, o que permitiu o bug passar despercebido. _(inferida do diff)_

**Arquivos impactados:**
- `test/frete.test.ts`

**Dependências:** act-001
