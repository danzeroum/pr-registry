# Implementa login social com Google (PROJ-88)

_PR-101 · exemplo-repo · requisito: PROJ-88 (Login social)_

## Resumo Geral

Este PR adiciona suporte a login social via Google, criando o endpoint de início do fluxo OAuth2, o serviço de troca de código por token/perfil, e testes de integração cobrindo o caminho feliz e o caso de token inválido.

## Resumo para Gestores

Os usuários agora conseguem entrar no sistema usando a conta do Google, sem precisar criar senha nova. A funcionalidade foi testada automaticamente antes de ir para produção.

## Ações

### Backend

#### act-001 — Criação

**Descrição:** Criação do endpoint /auth/google para iniciar o fluxo OAuth2 com o Google.

**Para gestores:** Agora o sistema aceita login com conta Google.

**Justificativa:** Permitir login com conta Google seguindo o padrão OAuth2 (RFC 6749), conforme solicitado no requisito PROJ-88.

**Arquivos impactados:**
- `src/routes/auth.ts`
- `src/services/oauth.ts`

```
router.post('/auth/google', async (req, res) => {
  const url = oauthService.buildAuthUrl();
  res.redirect(url);
});
```

**Impacto:**
- Requer configuração de credenciais OAuth no ambiente (GOOGLE_CLIENT_ID/SECRET).

#### act-002 — Criação

**Descrição:** Criação do serviço OauthService, responsável por trocar o código de autorização por um token e buscar o perfil do usuário no Google.

**Para gestores:** Criada a peça interna que conversa com o Google para confirmar quem é o usuário.

**Justificativa:** Encapsular a integração com o provedor OAuth2 em um serviço dedicado, reaproveitando o serviço de sessão já existente.

**Arquivos impactados:**
- `src/services/oauth.ts`

```
async function exchangeCode(code) {
  const token = await googleClient.getToken(code);
  return googleClient.getProfile(token);
}
```

**Dependências:** act-001

### Testes

#### act-003 — Criação

**Descrição:** Adição de testes de integração para o fluxo completo de login via Google, incluindo o caso de token inválido.

**Para gestores:** Criados testes automáticos para garantir que o login com Google continue funcionando corretamente.

**Justificativa:** Garantir cobertura de teste para um fluxo de autenticação crítico, evitando regressões futuras.

**Arquivos impactados:**
- `test/auth.google.test.ts`

**Dependências:** act-001, act-002
